    Worked methods

    Build a quadratic from its roots

    For roots 2 and −3, write (x − 2)(x + 3) = 0. Expand to x² + x − 6 = 0 and substitute both roots to check.

    Synthetic division by x − r

    Divide x³ − 4x + 3 by x − 1. Start with 1, 0, −4, 3. Bring down 1, then multiply by 1 and add in each column. Read 1, 1, −3, 0 as quotient x² + x − 3 and remainder zero.
