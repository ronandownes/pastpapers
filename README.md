# Irish School Maths Past Papers

A static GitHub Pages site for Irish state exam papers and marking schemes. The site opens with Leaving Certificate Ordinary Level Maths. Use By topic for the five existing Leaving Certificate topics and Junior Cycle revision by school year and exam level.

## Preview locally

Open index.html, or run python -m http.server from this directory.

## Maintain the catalogue

catalog.js stores subject rows as year, level, label, document type, source URL and source name. Topic rows record course, year, exam level, paper, question, topic, focus, PDF page, alternate index URL and marking scheme page. Page numbers are one-based PDF viewer pages.

Historical paper links come from Maynooth University. Marking scheme links go to the SEC directly where known or through the Better Exams download pages. The site serves its own interface and index. Exam PDFs stay at their source.

The initial Junior Cycle topic matches combine the existing Sets index with targeted text matches to the first- and second-year schemes of work. Verify any new question matches and PDF page targets before curating a class assignment.
