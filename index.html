Opening and saving PDFs in Chrome
  1. Paste chrome://settings/content/pdfDocuments into Chrome’s address bar. Choose Open PDFs in Chrome to read online, or Download PDFs to save automatically.
  2. To save one PDF while reading it, use the download button in Chrome’s PDF toolbar.
  3. Paste chrome://settings/downloads into the address bar. Under Location, select Change to pick a folder, or turn on Ask where to save each file before downloading.
  4. These settings apply to the Chrome profile you are using.
